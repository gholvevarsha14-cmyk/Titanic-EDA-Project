# Titanic EDA Project

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the Titanic dataset using Python. The objective is to understand the dataset, clean the data, visualize important patterns, and extract meaningful insights.

## Dataset
- Dataset: Titanic Dataset
- Source: Kaggle

## Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Tasks
- Loaded the dataset
- Checked dataset information
- Handled missing values
- Removed duplicate records
- Performed statistical analysis
- Created data visualizations
- Identified relationships between features
- Summarized key insights

## Visualizations
- Survival Count Plot
- Age Distribution Histogram
- Gender Distribution
- Correlation Heatmap
- Passenger Class Distribution
- Box Plots
- Scatter Plots

## Key Insights
- Female passengers had a higher survival rate than males.
- First-class passengers were more likely to survive.
- Younger passengers generally had better survival rates.
- Passenger class showed a strong relationship with survival.

## How to Run
1. Clone this repository.
2. Install the required libraries:
   ```
   pip install -r requirements.txt
   ```
3. Run the Python script:
   ```
   python eda_titanic.py
   ```
